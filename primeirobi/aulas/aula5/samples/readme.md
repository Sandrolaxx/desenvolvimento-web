# 🧠 Guia de Aula - Encontro 5: A Lógica da Web (Fundamentos de JavaScript)

Bem-vindos, desenvolvedores e desenvolvedoras, ao mundo da interatividade! ⚡

Se o HTML é o esqueleto e o CSS são as roupas, o **JavaScript** é o cérebro e o sistema nervoso da nossa página. É ele que permite que a nossa aplicação reaja aos cliques, processe dados e tome decisões.

Este repositório contém todos os códigos práticos vistos durante o Encontro 5. O objetivo aqui é que você execute, altere e até "quebre" esses arquivos para entender como o JavaScript funciona por debaixo dos panos.

---

## 🛠️ Pré-requisitos

Para rodar esses exemplos na sua própria máquina, você vai precisar de:

1. **[Git](https://git-scm.com/downloads)** instalado para clonar o repositório.
2. **[Node.js](https://nodejs.org/)** instalado. Ele é o motor que vai ler e executar o nosso código JavaScript fora do navegador (direto no seu terminal).
3. Um editor de código, como o **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)**.

---
